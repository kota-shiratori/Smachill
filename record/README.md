## 書き方の方針

ファイル名は `NN-スラッグ.md`（連番 + 内容がわかる英語スラッグ）。

各記録に入れておくと後で効くもの:

- **期間と成果** — 何ができるようになったか
- **最終構成** — 図。あとで見返したとき一番早く思い出せる
- **技術選定の理由** — 「なぜそれを選ばなかったか」も書く。判断の記録が一番価値がある
- **詰まったポイント集** — 症状 → 診断 → 原因 → 対処 → 教訓。**ブログにするならここが本体**
- **覚えたコマンド** — 特に診断系
- **現在地と残タスク** — 次回の再開地点

エラーメッセージは**実物をそのまま貼る**。あとで同じものを検索したときに自分の記録がヒットする。
